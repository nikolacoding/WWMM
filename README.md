## English
**WWMM** is a lightweight external C# trainer and mod menu designed for *Prince of Persia: Warrior Within* (`POP2.exe`). It manipulates game memory externally without requiring an internal DLL injection.

### Features
* **Invincibility**: Grants "god mode" (infinite health). Dying is still possible via fall damage or exiting the map borders (death by spikes or infinite, off-screen falling).
* **Infinite Sand**: Keeps your sand tanks fully filled.

### Requirements
* Windows 11 (w/ Administrator privileges)
* .NET Framework (10.0 or higher)

### Usage
1. Launch *Prince of Persia: Warrior Within* (`POP2.exe`).
2. Run `WWMM.exe` **as Administrator**.
3. Click **Check detection** to confirm connection.
4. Enable the desired cheats using the available checkboxes.

## Srpski
**WWMM** je lightweight vanjski C# mod meni dizajniran za *Prince of Persia: Warrior Within* (`POP2.exe`). Manipuliše memorijom igre eksterno, bez potrebe za DLL injekcijom.

### Funkcionalnosti
* **Invincibility**: Omogućava "god mode" (beskonačan health). Idalje je moguće umrijeti padanjem ili izlaskom van okvira mape (bodlje/šiljci ili padanje s mape van ekrana).
* **Infinite Sand**: Održava sand tankove uvijek potpuno punim.

### Zahtjevi
* Windows 11 (sa Administrator privilegijama)
* .NET Framework (10.0 i naviše)

### Upotreba
1. Pokreni *Prince of Persia: Warrior Within* (`POP2.exe`).
2. Pokreni `WWMM.exe` **kao Administrator**.
3. Pritisni **Check detection** da se provjeri da li je povezivanje uspjelo.
4. Uključiti željene cheatove koristeći dostupne checkboxeve.
